Drop a file in with the matching name and it appears on reload — no code
change. Until then the card shows the tinted number panel instead, so nothing
looks broken.

Landscape works best: roughly 900x700 or wider. The bottom-right corner is
covered by a large numeral over a gradient wash, so keep faces out of it.
